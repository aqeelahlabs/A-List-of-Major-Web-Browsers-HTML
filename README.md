# List of Browsers and Descriptions

A simple web page listing major web browsers with a short description of each, built using a description list. Built as part of the freeCodeCamp curriculum.

## Live Demo

 https://aqeelahlabs.github.io/A-List-of-Major-Web-Browsers-HTML/

## Features

- A main heading introducing the list of major web browsers
- Five browsers (Google Chrome, Firefox, Safari, Brave and Arc), each paired with a description
- Descriptions covering who developed each browser and when it was first released

## What I Practised

- Structuring a basic HTML5 page
- Creating a description list with the `dl` element
- Pairing terms (`dt`) with their descriptions (`dd`)
- Making the page responsive with the viewport `meta` tag

## Built With

- HTML5
